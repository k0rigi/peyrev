Solutions · E-commerce

Automatisez les tâches de vos places de marché et de votre boutique.

Les connexions Trendyol, Hepsiburada, Shopify et WooCommerce sont prêtes à l'emploi : il vous suffit de saisir vos propres identifiants d'API. Pour les back-offices sans API, Peyrev utilise le navigateur à votre place.

Que peut-on faire ?

Les tâches que Peyrev prend en charge

  • Toutes les commandes au même endroitRécupérez les commandes via les services des places de marché et écrivez-les dans Excel, dans Google Sheets ou dans votre propre base de données.
  • Alerte de seuil de stockContrôle les stocks à intervalles réguliers et signale aux achats, par Telegram, Teams ou e-mail, les produits passés sous le seuil.
  • Saisie en masse dans les back-officesSaisit ligne par ligne dans un panneau web une liste de produits ou de clients issue d'un tableau, et réécrit dans le tableau le résultat de chaque ligne.
  • Tenez vos clients informésEnvoyez une notification par WhatsApp Business, SMS ou e-mail quand l'état d'une commande ou d'une livraison change.

Connexions prêtes à l'emploi

Se connecte aux services que vous utilisez

Dans Peyrev, la rubrique Bağlantılar (Connexions) propose des connexions prêtes à l'emploi pour 43 services : il vous suffit de saisir vos propres informations. Les mots de passe restent dans le coffre de votre ordinateur. Les plus utilisées dans ce domaine :

  • Trendyol Satıcı API
  • Hepsiburada Pazaryeri (commandes)
  • Shopify
  • WooCommerce
  • Stripe
  • WhatsApp Business
  • Twilio (SMS)
  • Telegram
  • Google Sheets
  • Mailchimp
  • HubSpot
  • Zendesk
