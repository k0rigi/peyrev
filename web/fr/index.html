Le studio de flux pour Windows et macOS

Confiez vos tâches répétitives à Peyrev.

Automatisez par des flux visuels ce que vous faites à la main dans vos applications de bureau et sur des sites web. Enchaînez les étapes, ajoutez des conditions et des boucles, puis lancez le flux en un clic ou selon un planning. Si vous le souhaitez, des agents d'IA utilisent vos flux dans les limites que vous fixez.

Fonctionnalités

Configurez une fois ce que vous faites à la main, Peyrev le répète.

Les captures ci-dessous proviennent de Peyrev lui-même, avec des flux d'exemple.

01 · Concevez

Choisissez les étapes dans la bibliothèque, le flux se construit tout seul.

Ajoutez au diagramme l'une des 108 étapes réparties entre les catégories fenêtres, souris et clavier, écran, fichiers et Excel, données, Google Sheets, base de données, web, e-mail et API. La sortie d'une étape devient une variable pour l'étape suivante ; le flux se lit de gauche à droite, du début à la fin.

  • Recherche d'étapes et favoris
  • Création d'étapes par enregistrement de vos gestes
  • Aperçu : essai sans utiliser l'écran

02 · Reliez

Conditions, boucles et chemins d'erreur dans le diagramme.

Ouvrez le flux en diagramme : la boucle « Her satır için » (pour chaque ligne), les branches vrai et faux de « Koşul » (condition), le bloc « Hata olursa » (en cas d'erreur) et les liens « Adıma git » (aller à l'étape) apparaissent d'un coup d'œil. Pour changer un chemin, faites glisser le point d'une case vers une autre case.

  • Trace de la dernière exécution sur le diagramme
  • Exécution jusqu'à l'étape choisie
  • Test d'une étape isolée

03 · Réglez

Chaque étape explique comment l'utiliser.

Un clic sur une étape ouvre à droite ses réglages et un court guide. Pour les étapes de clic et de saisie, vous désignez la cible à l'écran ; Peyrev reconnaît la fenêtre et le champ d'après la structure même de l'application. Si la cible est introuvable, l'étape s'arrête : elle ne clique pas au hasard.

  • Sélection de la cible à l'écran
  • Copie des variables d'un clic
  • Choix de la suite après chaque étape

04 · Planifiez

Vos flux s'exécutent d'eux-mêmes selon le calendrier.

Lancez un flux à heures fixes, chaque jour, certains jours de la semaine ou à intervalles réguliers. La vue calendrier montre le planning de la semaine, la prochaine tâche et les chevauchements ; les flux qui utilisent l'écran s'exécutent l'un après l'autre, les autres en arrière-plan.

  • Priorité et délai de démarrage maximal
  • Rattrapage au lancement d'une exécution manquée pendant que Peyrev était fermé
  • Lancement d'un flux à la fin d'un autre

05 · Suivez

Chaque exécution laisse une trace.

L'historique des exécutions indique pour chaque flux quand il a tourné, combien de temps il a pris et avec quel résultat il s'est terminé. Le détail contient le journal étape par étape et les fichiers produits ; affichez l'exécution sur le diagramme pour voir où elle s'est arrêtée.

  • Journal d'exécution étape par étape
  • Téléchargement des fichiers produits
  • Capture d'écran dans l'étape « Hata olursa » (en cas d'erreur)

Agents option

Votre équipe numérique travaille dans le même bureau.

Les agents d'IA utilisent les flux et les capacités que vous leur confiez, dans les limites que vous autorisez. Vous suivez votre équipe dans un bureau en 3D : qui a pris une tâche, qui a posé une question, qui a livré le résultat.

  • 01

    L'agent responsable répartit le travail

    Vous confiez la tâche à l'agent responsable ; il la répartit entre les services, répond aux questions et rassemble les résultats.

  • 02

    Uniquement les flux que vous autorisez

    Chaque agent de service n'exécute que les flux que vous lui avez ouverts ; aucun n'accède sans autorisation aux informations d'un autre.

  • 03

    Les actions irréversibles attendent votre accord

    Les flux comportant des étapes qui écrivent, envoient ou suppriment attendent votre approbation, sauf si vous en avez décidé autrement en accordant l'autorisation.

  • 04

    Votre propre modèle

    Les agents fonctionnent avec votre propre connexion à un modèle d'IA ; tâches, coûts et durées s'affichent dans l'écran de performance.

Exemples de flux

Chaque service a ses tâches répétitives.

Ces diagrammes sont des flux d'exemple construits dans Peyrev ; chaque case est une véritable étape de la bibliothèque. Cliquez sur un diagramme pour l'agrandir ; vous pouvez tous les télécharger comme modèles et les importer dans Peyrev.

  • Comptabilité

    Saisie de factures : d'Excel vers l'ERP

    Saisit ligne par ligne les factures d'un fichier Excel dans l'écran de facturation de l'ERP ; note celles qu'il n'a pas pu saisir, fait le compte rendu des factures traitées et prévient la comptabilité par e-mail.

  • Finance

    Taux de change du jour

    Lit le tableau de la page des taux de change, l'écrit dans Excel et prévient l'équipe sur Telegram. Automatiquement, chaque matin de semaine à 9 h.

  • Comptabilité

    Archiver les factures PDF

    Lit le PDF des factures reçues dans la boîte de réception ; s'il trouve le montant, il range le fichier dans le dossier du mois, sinon il le laisse à vérifier.

  • Entrepôt

    Alerte de stock critique

    Contrôle les stocks de la base de données toutes les deux heures ; liste les produits passés sous le seuil et prévient les achats.

  • Ventes

    Saisie en masse dans un formulaire web

    Saisit un à un dans un panneau web les clients d'une liste Google Sheets et réécrit dans le tableau le résultat de chaque ligne.

  • Ressources humaines

    Distribuer les bulletins de paie

    Liste les bulletins de paie PDF d'un dossier, retrouve chaque salarié grâce au matricule figurant dans le nom du fichier et lui envoie son bulletin par e-mail.

Comment obtenir Peyrev ?

Dès que votre paiement est confirmé, vous recevez par e-mail votre lien de téléchargement personnel, qui donne accès aux installateurs Windows et macOS, avec vos identifiants de connexion. L'application installée vérifie d'elle-même les nouvelles versions et les télécharge après vérification ; vos flux et vos réglages sont conservés lors des mises à jour. L'interface de l'application Peyrev est actuellement en turc.

Sous Windows, Microsoft Edge WebView2 est nécessaire. Sur Mac, les autorisations Enregistrement de l'écran et Accessibilité sont demandées pour reconnaître et piloter les fenêtres.

Vous avez déjà un compte ?

La connexion à Peyrev ne se fait pas depuis cette page, mais dans l'application : avec l'adresse e-mail de votre compte (ou votre nom d'utilisateur) et votre mot de passe.

La date de fin de votre licence s'affiche dans l'application, rubrique Ayarlar → Peyrev lisansı (Réglages → Licence Peyrev) ; c'est aussi là que vous changez votre mot de passe.

Pour prolonger votre licence, remplissez ce formulaire avec l'adresse e-mail de votre compte et choisissez la formule souhaitée. Aucun nouveau compte n'est créé et le champ mot de passe ne modifie pas votre mot de passe actuel ; votre demande nous parvient et nous vous communiquons les modalités de paiement.

Si l'on vous a remis un code de mot de passe, définissez votre propre mot de passe avec Şifre kodum var (j'ai un code de mot de passe) sur l'écran de connexion.

Votre compte ne peut être ouvert que sur un seul ordinateur à la fois ; si vous vous connectez sur un autre ordinateur, la session précédente se ferme.

Questions

Questions fréquentes

Si vous ne trouvez pas la réponse à votre question, écrivez-nous depuis Peyrev avec le bouton Öneri ve destek (suggestions et assistance).

Faut-il savoir programmer pour utiliser Peyrev ?

Non. Les flux se construisent avec des étapes choisies dans la bibliothèque, et chaque étape explique comment l'utiliser. Pour les étapes de clic et de saisie, vous désignez la cible à l'écran.

Combien ça coûte ?

Pour connaître nos tarifs, écrivez-nous via le formulaire de contact ou à info@peyrev.com : nous vous enverrons par e-mail le prix de la formule qui vous convient. L'abonnement est mensuel et vous pouvez arrêter quand vous le souhaitez ; vous continuez d'utiliser Peyrev jusqu'à la fin de la période payée.

Où télécharger Peyrev ?

Dès que votre paiement est confirmé, votre lien de téléchargement personnel vous parvient par e-mail ; il est valable 30 jours. S'il a expiré ou si vous ne retrouvez pas l'e-mail, écrivez à info@peyrev.com et nous vous en enverrons un nouveau.

Faut-il une connexion Internet pour utiliser Peyrev ?

Oui. La licence est vérifiée via peyrev.com à chaque ouverture ; une connexion Internet est nécessaire pour ouvrir l'application. Vos flux, vos réglages de connexion et vos historiques d'exécution restent en revanche sur votre ordinateur.

Puis-je utiliser mon compte sur plusieurs ordinateurs ?

Votre compte ne peut être ouvert que sur un seul ordinateur à la fois ; si vous vous connectez sur un autre ordinateur, la session précédente se ferme.

Comment arrivent les mises à jour ?

L'application installée vérifie d'elle-même les nouvelles versions et les télécharge après vérification ; vos flux et vos réglages sont conservés lors des mises à jour.

Les flux planifiés s'exécutent-ils quand l'ordinateur est éteint ?

Non. Le planificateur fonctionne sur cet ordinateur, lorsque Peyrev est ouvert. Si vous le souhaitez, une exécution manquée pendant que Peyrev était fermé est effectuée une fois à l'ouverture.

Avec quel modèle d'IA les agents fonctionnent-ils ?

Les agents fonctionnent avec le modèle que vous connectez : OpenAI, Gemini, Anthropic ou un modèle local sur votre propre ordinateur. La clé de votre connexion au modèle est conservée dans le coffre du système d'exploitation.

Comment prolonger ma licence ?

Remplissez le formulaire de demande avec l'adresse e-mail de votre compte et choisissez la formule souhaitée. Aucun nouveau compte n'est créé et le champ mot de passe ne modifie pas votre mot de passe actuel ; votre demande nous parvient et nous vous communiquons les modalités de paiement.

On m'a remis un code de mot de passe, que dois-je faire ?

Sur l'écran de connexion de Peyrev, choisissez Şifre kodum var (j'ai un code de mot de passe), puis saisissez votre nom d'utilisateur, le code et le mot de passe de votre choix. Le code ne sert qu'une fois.

Quelles autorisations sont demandées sur Mac ?

Les autorisations Enregistrement de l'écran et Accessibilité sont demandées pour reconnaître et piloter les fenêtres. Sous Windows, Microsoft Edge WebView2 est nécessaire.
