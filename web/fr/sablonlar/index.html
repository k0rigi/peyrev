Bibliothèque de modèles

Démarrez avec des flux prêts à l'emploi.

Chaque modèle est un flux fonctionnel construit dans Peyrev. Téléchargez-le, importez-le dans Peyrev, puis adaptez les chemins de fichiers, les adresses et les connexions à votre activité.

  1. Téléchargez

    Cliquez sur Télécharger le modèle : un petit fichier .json est enregistré sur votre ordinateur.

  2. Importez dans Peyrev

    Dans Peyrev, cliquez sur Akışlar → İçe aktar (Flux → Importer) et choisissez le fichier. Le flux est ajouté à votre liste ; il ne se lance pas tout seul.

  3. Adaptez

    Modifiez les chemins de fichiers, les adresses et les connexions selon votre environnement ; testez d'abord étape par étape, puis planifiez.

  • Comptabilité

    Saisie de factures : d'Excel vers l'ERP

    Saisit ligne par ligne les factures d'un fichier Excel dans l'écran de facturation de l'ERP ; note celles qu'il n'a pas pu saisir, fait le compte rendu des factures traitées et prévient la comptabilité par e-mail.

    11 étapes. Prérequis : liste des factures (Excel), écran de facturation de l'ERP, connexion e-mail.

    Télécharger le modèle

  • Finance

    Taux de change du jour

    Lit le tableau de la page des taux de change, l'écrit dans Excel et prévient l'équipe. Avec le planificateur, il peut s'exécuter automatiquement chaque matin de semaine.

    4 étapes. Prérequis : fichier Excel où écrire les taux, canal de notification défini dans les Réglages (par ex. Telegram).

    Télécharger le modèle

  • Comptabilité

    Archiver les factures PDF

    Lit le PDF des factures reçues dans la boîte de réception ; s'il trouve le montant, il range le fichier dans le dossier du mois, sinon il le laisse à vérifier.

    6 étapes. Prérequis : connexion de lecture des e-mails (IMAP), dossier d'archive.

    Télécharger le modèle

  • Entrepôt

    Alerte de stock critique

    Contrôle les stocks de la base de données ; liste les produits passés sous le seuil et prévient les achats.

    6 étapes. Prérequis : connexion à la base de données (table des stocks), canal de notification.

    Télécharger le modèle

  • Ventes

    Saisie en masse dans un formulaire web

    Saisit un à un dans un panneau web les clients d'une liste Google Sheets et réécrit dans le tableau le résultat de chaque ligne.

    7 étapes. Prérequis : connexion Google Sheets, adresse du panneau web où effectuer la saisie.

    Télécharger le modèle

  • Ressources humaines

    Distribuer les bulletins de paie

    Liste les bulletins de paie PDF d'un dossier, retrouve chaque salarié grâce au matricule figurant dans le nom du fichier et lui envoie son bulletin par e-mail.

    7 étapes. Prérequis : dossier des bulletins de paie, base de données contenant la liste des salariés, connexion d'envoi d'e-mails (SMTP).

    Télécharger le modèle

Les flux partagés par les membres se trouvent dans la Communauté (en turc). Seuls les titulaires d'un compte Peyrev peuvent exécuter un modèle ; si vous n'avez pas de compte, faites une demande.
