Web sayfası aç

Bilgisayardaki Edge veya Chrome ile sayfayı açar; sonraki web adımları bu sayfada çalışır. Tarayıcı, çalışma bitince kapanır; girişler ayrı Peyrev profilinde hatırlanır.

Nasıl kullanılır?

  1. Adresi yazın (https://…).
  2. Tarayıcıyı seçin; Otomatik Windows'ta Edge, Mac'te Chrome kullanır.
  3. Sonra Web alanını doldur, Web öğesine tıkla ve Web'den metin oku adımlarını ekleyin.

Sonuç

${web_url}: açılan sayfanın adresi.

İpucu. Tarayıcı çalışma bitince kapanır. Girişler Peyrev'in ayrı profilinde hatırlanır; kendi tarayıcınızın profili kullanılmaz.

Alanlar (4)
Adres zorunlu
http:// veya https:// ile başlamalıdır.
Tarayıcı
Seçilen tarayıcı bilgisayarda kurulu olmalıdır; ayrıca tarayıcı indirilmez. Seçenekler: Otomatik (Windows: Edge, Mac: Chrome), Microsoft Edge, Google Chrome.
Tarayıcıyı göstermeden çalıştır
Açıkken pencere görünmez. Giriş veya doğrulama gereken sitelerde kapalı bırakın.
Sonucu değişkene kaydet zorunlu
Açılan sayfanın son adresi (yönlendirmelerden sonra).

74

Web öğesine tıkla

Açık sayfada düğme, bağlantı veya metne tıklar. Hedef birden fazla öğeyle eşleşirse tıklamaz.

Nasıl kullanılır?

  1. Hedefi bulma yöntemini seçin; düğmeler için Düğme veya bağlantı adı.
  2. Hedef'e sayfada görünen yazıyı yazın (ör. Kaydet).
  3. Gerekirse Tıklama türünü değiştirin: çift tık, sağ tık, orta tık veya tıklamadan yalnız üzerine gelme.

İpucu. Hedef birden fazla öğeyle eşleşirse tıklanmaz; Tam eşleşmeyi açın veya daha ayırt edici bir yazı kullanın. Tıklama tekrarlanmaz.

Alanlar (6)
Hedefi bulma yöntemi zorunlu
Görünen metin, alan etiketi veya düğme adı çoğu sitede yeterlidir; CSS yalnız gerekirse. Seçenekler: Görünen metin, Alan etiketi, Alandaki silik yazı (yer tutucu), Düğme veya bağlantı adı, CSS seçici (gelişmiş).
Hedef zorunlu
Sayfada görünen yazı (ör. Giriş yap, Fatura No) veya CSS seçici (ör. #kullanici).
Tam eşleşme
Kapalıyken yazdığınız metnin içinde geçmesi yeterlidir; büyük/küçük harf fark etmez.
En fazla bekle (saniye)
Hedef görünene kadar bekler; süre dolarsa adım durur.
Çerçeve (iframe)
Hedef sayfanın içindeki bir çerçevedeyse çerçevenin CSS seçicisi (ör. iframe#icerik). Boş: sayfanın kendisi.
Tıklama türü zorunlu
Tek tık çoğu düğme ve bağlantı için yeterlidir. Çift tık satır veya dosya açar; sağ tık sitenin kendi sağ tık menüsünü açar. Üzerine gel tıklamaz; fareyle açılan menüleri gösterir. Seçenekler: Tek tık, Çift tık, Sağ tık, Orta tık, Yalnız üzerine gel (tıklamaz).
