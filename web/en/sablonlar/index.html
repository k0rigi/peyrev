Template library

Start with ready-made flows.

Every template is a working flow built in Peyrev. Download it, import it into Peyrev, and change the file paths, addresses and connections to fit your work.

  1. Download

    Click Download template; a small .json file is saved to your computer.

  2. Import into Peyrev

    In Peyrev, click Akışlar → İçe aktar (Flows → Import) and choose the file. The flow is added to your list; it doesn't run on its own.

  3. Adapt

    Change the file paths, addresses and connections to match your setup; test it step by step first, then schedule it.

  • Accounting

    Invoice entry: from Excel to your ERP

    Enters the invoices from Excel into the ERP's invoice screen row by row; notes any it can't enter, reports what was processed and emails accounting.

    11 steps. You need: an invoice list (Excel), the ERP's invoice screen, an email connection.

    Download template

  • Finance

    Daily exchange rates

    Reads the table on an exchange rate page, writes it to Excel and notifies the team. With the scheduler, it can run automatically every weekday morning.

    4 steps. You need: an Excel file to write the rates to, a notification channel set up in Settings (Ayarlar), e.g. Telegram.

    Download template

  • Accounting

    Archive PDF invoices

    Reads the PDF of each invoice in the inbox; if it finds the amount, it moves the file to that month's folder, otherwise it leaves it for review.

    6 steps. You need: an email reading (IMAP) connection, an archive folder.

    Download template

  • Warehouse

    Critical stock alert

    Checks stock levels in the database; lists products below the threshold and notifies purchasing.

    6 steps. You need: a database connection (stock table), a notification channel.

    Download template

  • Sales

    Bulk entry into a web form

    Enters the customer list from Google Sheets into a web panel one by one and writes each row's result back to the sheet.

    7 steps. You need: a Google Sheets connection, the address of the web panel to enter data into.

    Download template

  • Human resources

    Distribute payslips

    Lists the payslip PDFs in a folder, finds each employee by the staff number in the file name and emails them their payslip.

    7 steps. You need: a payslip folder, a database with the employee list, an email sending (SMTP) connection.

    Download template
